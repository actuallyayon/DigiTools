# DigiTools

A modern digital product marketplace built with React, where users can browse, explore, and purchase premium AI tools, design assets, and productivity software.

**Live Site:** [DigiTools](https://actuallyayon.github.io/DigiTools/)

## Technologies Used

- React 19
- Vite 8
- Tailwind CSS 4
- JavaScript (ES6+)

## Features

- **Responsive Design** — Fully optimized for mobile, tablet, and desktop with a collapsible navigation menu.
- **Interactive Product Marketplace** — Browse digital tools with real-time cart functionality and dynamic product cards.
- **Modern UI/UX** — Clean interface with smooth animations, gradient accents, and a consistent design system.
